⚙ TPM V6.0 — Düzeltme Aracı

Sayfayı Yenile düğmesinin sizi personel seçimine göndermesini önlemek ve Supabase canlı veri güncellemelerini eklemek için hazırlanmıştır.

1. Orijinal index.html dosyanızı seçin

Dosyayı GitHub deponuzdan indirin. Bu işlem yalnızca bilgisayarınızda çalışır; hiçbir dosya başka yere yüklenmez.

2. Yeni dosyayı oluşturun

Hazır. Orijinal index.html seçilmesini bekliyorum.

3. Yayınlama

  1. İndirilen yeni index.html dosyasını GitHub'daki aynı dosyanın yerine koyun.
  2. Supabase SQL Editor'da paketteki Supabase_Realtime_Ayar.sql kodunu çalıştırın.
  3. Telefonda ve bilgisayarda giriş yapıp personel seçin; veriler otomatik güncellenirken sayfa yeniden açılmamalıdır.

Eski dosyanız yerinde kalır. Düzeltici veri tabanına bağlanmaz. GitHub dosyanızın yedeğini saklayın. Canlı ortamda uygulamadan önce test edin.
